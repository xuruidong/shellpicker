# 背单词 CLI 工具（study.py）实现计划

## Context

用户已在 `WordsOut-main` 项目里爬取了扇贝单词书数据，存入 `shanbay.db`（SQLite）：

- `words`: 2786 词（1523 学过 / 1263 未学），含音标、音频链接、labels、familiarity
- `senses`: 6642 条释义（pos + 中文/英文释义，含 dictionary_id）
- `examples`: base 例句 ~1962 条（词典例句，中英对照），ext 真题例句 2686 条（含出处、年份、star、sense_cn），约 1481 词有真题例句，1017 词两种例句都有

用户想通过**例句中文提示来背句子、背单词**。已确认的需求：

- 场景：终端问答式（交互式 TUI），程序随机抽词
- 练习形式：**中文句挖空 → 回忆英文整句**（显示中文翻译，试回忆英文原句，再显示答案自评）
- 调度：**SM-2 简化版**（答对间隔×2.5，答错重来），进度存 SQLite
- 界面：**纯标准库**（print / input），不引入第三方依赖
- **例句优先用词典例句（base），没有词典例句的词用真题例句（ext）兜底**
- **两种练习模式**（运行时选择，详见下）：
  - 模式一（默认）：四层递进，用户输入英文原句，程序比对判分
  - 模式二（听力模式）：第 1 层只给例句发音（播放音频），后面与模式一相同
- **答对（输入正确句子）才算完成；在挖空层才写出单词 → 该句标记为「不熟」**

## 方案设计

### 数据层（复用现有 shanbay.db，不改表）

在 `shanbay.db` 中新增一张复习进度表（words/senses/examples 只读）：

```sql
CREATE TABLE IF NOT EXISTS study (
    vocab_id     TEXT PRIMARY KEY,     -- 关联 words.vocab_id
    ease         REAL DEFAULT 2.5,     -- SM-2 的 EF 因子
    interval     INTEGER DEFAULT 0,    -- 当前复习间隔（天）
    due_date     TEXT,                 -- 下次复习日期 YYYY-MM-DD
    reps         INTEGER DEFAULT 0,    -- 成功次数
    lapses       INTEGER DEFAULT 0,    -- 失败次数
    last_review  TEXT                  -- 最近复习时间
);
```

- 新词首次练习时插入该表（due_date = 明天或按评分计算）
- 例句选择：每词优先取 `kind='base'` 词典例句；没有 base 的词用 `kind='ext'` 真题例句兜底；每词选一条，多次复习可轮流用（按 reps 取模轮换）
- 例句音频：base 例句无整句音频，ext 例句有 `audio_us`（mp3 直链，无需鉴权）；播放时回退到单词本身的 `words.audio_us`（2786 词全有）。播放方案：Windows 下 `os.startfile(下载的临时文件)`；提供 `--no-audio` 开关跳过

### 练习流程

#### 模式一（默认）：四层递进，输入英文原句

每张卡片四层递进，**用户在每层输入英文原句，输入正确（模糊匹配：忽略大小写、标点、多余空格、`<vocab>` 标签位置的目标词及其词形变化）才算进入下一层/完成**：

1. **第 1 层 — 中文例句 + 目标词标注**：显示该词例句的中文翻译，其中对应目标词的位置用【 】标出（如「话题【突然的】转变让他很吃惊」——若中文无法精确定位则整句显示）；同时可输入 `p` 播放发音；输入正确的英文原句 → **完成（熟句）**
2. **第 2 层 — 完整释义**：显示单词的完整 senses（词性 + 中文释义 + 音标）；输入正确的英文原句 → **完成（熟句）**
3. **第 3 层 — 英文挖空**：显示英文例句，目标词替换为 `______`；用户需**写出正确的单词**（不要求整句）→ **此句标记为不熟（SM-2 中最多给 3 分）**
4. **第 4 层 — 答案**：完整英文例句（目标词大写）+ 中文翻译；用户自评 0-5 分（此层才看答案 → 0-2 分）

判定规则：
- 第 1/2 层答出整句 → 熟（评 4-5 分，SM-2 正常递增间隔）
- 第 3 层才写出单词 → 不熟（给 2-3 分，间隔设为 1 天，**近期仍会安排复习**）
- 第 4 层才看到答案 → 忘了（0-1 分，间隔重置，今天内重现）

「不熟」= 该句近期（明天）还会出现在复习队列里，直到某次在第 1/2 层直接答出整句才会拉长间隔。

#### 模式二（`--listening`）：听力模式

- 第 1 层只给例句发音（自动下载并播放），不显示文字
- 后续各层与模式一完全相同（第 2 层释义 → 第 3 层挖空 → 第 4 层答案）
- 适合练听写；可随时输入 `p` 重听

示例输出（模式一）：

```
[1/20] 复习 | 词性: adj.
  中文: 话题【突然的】转变让他很吃惊。
  (输入英文句子 / p=发音 / 回车=看下一层提示)
> the abrupt change of subject surprised him
✓ 熟句！
  完整: The ABRUPT change of subject surprised him.
```

答错时进入下一层；第 3 层输入目标词（如 `abrupt`，忽略大小写）即算「不熟」完成；第 4 层直接看答案给 0-1 分。

会话逻辑：

- 每轮 `python study.py` 开始：取 due_date <= 今天的词 + 若数量不足则补充新词（默认 20 张卡，`--new N --review N` 可调）
- 卡片顺序：过期的按 due_date 升序，新词随机穿插
- 结束时打印统计：今日复习数、正确率、下次复习分布
- 结束时把进度写回 SQLite（每张卡评完即时 commit，可随时 Ctrl+C 退出不丢进度）

### 例句范围

- 优先 base（词典例句，约 1960 词有）；没有 base 的词用 ext（真题）兜底（合计约 2424 词有例句）
- 默认只出有例句的词；`--all` 开关放开到全部 2786 词（无例句的词退化为"中文释义→回忆拼写"模式）

### 新文件

- `study.py` — 全部逻辑单文件（~400 行）：
  - `load_due_cards(conn, limit)` — 取到期卡 + 新卡
  - `pick_example(...)` — 每词选一条例句（base 优先，ext 兜底；按 reps 轮换）
  - `blank_word(content_en)` — 把 `<vocab>xxx</vocab>`（含词形变化）替换为 `______`
  - `norm(s)` / `check_sentence(input, target)` — 忽略大小写/标点/空格的模糊比对
  - `check_word(input, content_en, word)` — 挖空单词比对（兼容词形变化）
  - `play_audio(url)` — 下载音频到临时文件并用系统默认播放器打开（Windows `os.startfile`）
  - `sm2_update(card, grade)` — 纯函数，返回更新后的字段
  - `run_card(...)` — 单张卡的四层递进循环
  - CLI 参数：`--new N`（默认 10）、`--review N`（默认 20）、`--listening`（听力模式）、`--all`、`--no-audio`

## 不做的事

- 不做 GUI / Web（用户已确认命令行版先行）
- 不改 words_tool.py 的爬虫逻辑，不继续爬数据
- 不引入第三方库
- 自动判分只做「整句模糊比对」和「挖空单词精确比对（忽略大小写）」，不做部分给分

## 验证

1. `python study.py --new 3 --review 3` 跑一轮完整会话（模式一），确认：抽卡、四层递进、输入判分（大小写/标点容错）、进度入库
2. `python study.py --listening --new 2` 确认听力模式第 1 层播放音频、后续层正常
3. 故意输错句子，确认进入下一层且 SM-2 分数按预期降低
4. 会话中断（Ctrl+C）后重新运行，确认进度保留、不会重复抽已评分的卡
5. 修改 SQLite 中某词 due_date 为过去日期，确认下次运行被抽为复习卡
6. 对没有 base 例句、只有 ext 例句的词跑一遍，确认例句兜底路径正常
