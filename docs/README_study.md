# 背单词 CLI 工具（study.py）

基于 `shanbay.db`（由 `words_tool.py` 爬取生成）的例句中文提示回忆练习工具。

## 快速开始

```bash
python study.py                      # 默认：10 个新词 + 20 个复习词
python study.py --new 20 --review 10 # 自定义新词/复习数量
python study.py --listening          # 听力模式（第 1 层只听发音）
python study.py --all                # 允许没有例句的词
python study.py --no-audio           # 不播放音频
```

退出：随时 `Ctrl+C`，已完成的卡片进度已保存，下次运行不会重复。

## 练习流程（四层递进）

每张卡片，越早答出说明记得越牢：

| 层 | 提示内容 | 答对意味着 | 记分 |
|---|---|---|---|
| 1 | 中文例句（目标词用【】标出），可 `p` 播放发音 | 写出英文整句 | 熟（5 分） |
| 2 | 完整释义（词性 + 中文 + 英文 + 音标） | 写出英文整句 | 熟（4 分） |
| 3 | 英文例句，目标词挖空 `______` | 写出目标单词 | **不熟**（3 分） |
| 4 | 答案（目标词大写）+ 中文翻译 | — | 忘了（1 分） |

- **熟**：SM-2 间隔递增（1 天 → 6 天 → ×2.5 递增）
- **不熟**：间隔回到 1 天，明天还会出现
- **忘了**：今天内会再次出现

## 交互按键

- 直接输入英文句子 / 单词 → 提交答案
- 直接回车 → 跳过当前层，看下一层提示
- 输入 `p` → 重播发音

## 判分规则

- 整句比对：忽略大小写、标点、多余空格；`<vocab>` 内的词形变化也兼容
- 挖空单词比对：忽略大小写，接受原形或例句中的变形（如 `acclaimed` 也认 `acclaim`）

## 数据说明

- 例句优先用词典例句（`base`，简短日常）；没有词典例句的词用真题例句（`ext`，含出处/年份/星级）兜底
- **词典例句没有整句朗读音频**，`p=发音` 会回退到单词本身的发音（所有词都有）；只有真题例句的词才有整句朗读
- 复习进度存于 `shanbay.db` 的 `study` 表（自动创建）
